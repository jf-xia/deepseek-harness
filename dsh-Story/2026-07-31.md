## 2. 设计模式与重构

### 应用的设计模式

- **Quiet Navigation Pattern**：`feat(directory-picker-browse): quiet navigation — one-frame landings and a slow-scan loading pill` 引入了安静导航模式，目录浏览时通过 loading pill 提供视觉反馈，避免频繁的页面闪烁。
- **Adaptive Default Pattern**：`feat(host): adaptive directory-picker default via -auto chooser` 实现了自适应默认选择，directory picker 可以根据使用场景自动选择 dialog 或 browse 后端。
- **Collapsed ToolRow Pattern**：`refactor(web-cards): route read/search/web/diff rows through collapsed ToolRow` 将多种 card 的工具行统一为折叠的 ToolRow，简化了 card 的交互模式。
- **Session Archive Pattern**：`feat(workspace): add registry-global archivedSessionIds set` 引入了 session 归档机制，通过 `archivedSessionIds` 集合管理归档的 session。
- **Locale Seat Pattern**：`feat(client): typed locale standard seat in the slot framework` 引入了 locale seat，通过 slot 框架管理 locale 状态，支持浏览器语言检测和设置语言推导。
- **TUI Welcome Overlay Pattern**：`feat(tui)!: consolidate terminal UI improvements` 将 TUI 首次运行欢迎重构为 overlay 模式，通过 overlay 提供首次运行引导。

### 模块解耦与接口定义

- **Directory Browser Navigation**：将目录浏览导航拆分为 quiet navigation、adaptive default、show-hidden toggle，每个职责独立。
- **Web Cards Presenter**：将 web cards 从简单的 card 渲染重构为 presenter 模式，每个 card 有自己的 presenter 和 tool-row。
- **Session Archive**：将 session 归档拆分为 registry、RPC、UI，每个职责独立。
- **Locale System**：将 locale 管理拆分为 seat、browser detection、settings derivation，每个职责独立。

### 基础设施与性能

- **Quiet Navigation**：通过 one-frame landings 和 slow-scan loading pill 优化了目录浏览的性能和用户体验。
- **Collapsed ToolRow**：通过折叠 ToolRow 简化了 card 的交互模式，减少了 DOM 元素数量。
- **TUI Resume Scan**：`feat(tui): open the /resume picker immediately with a loading state` 通过立即显示 loading 状态优化了 TUI 的恢复扫描体验。

## 3. 特性交付与系统影响

### 核心特性

- **Workspace Directory Browser**：这是当日最大的架构交付之一。quiet navigation、adaptive default 和 show-hidden toggle 共同建立了 workspace 目录浏览的完整体验，支持 native 和 web 两种模式。
- **LLM Onboarding Config**：dynamic config、web config plane 和 DeepSeek onboarding 共同建立了 LLM provider 的配置和 onboarding 机制，支持自定义 DeepSeek 模型。
- **Web Cards Presenter**：read、search、web、diff 四种 presenter card 和 collapsed tool-row 共同建立了工具输出的多样化渲染机制。
- **Session Archive**：registry、RPC 和 UI 共同建立了 session 归档机制，支持 session 的归档和恢复。
- **Locale System**：seat、browser detection 和 settings derivation 共同建立了 locale 管理机制，支持多语言和本地化。
- **TUI Welcome**：overlay、resume scan 和 /details command 共同建立了 TUI 首次运行引导机制。

### 系统拓扑影响

- **Directory Browser 导航路径**：quiet navigation 改变了目录浏览的导航路径，从频繁的页面刷新变为 one-frame landings。
- **Web Cards 渲染路径**：presenter card 改变了工具输出的渲染路径，从简单的 card 渲染变为 presenter 模式。
- **Session 归档路径**：session archive 建立了 session 归档的新路径，从直接删除变为归档。
- **Locale 管理路径**：locale seat 改变了 locale 的管理路径，从硬编码变为 slot 框架管理。

## 4. 架构决策与 Roadmap 对齐

### 关键技术决策（ADR 推断）

**ADR-015: Quiet Navigation for Directory Browser**
- **背景与痛点**：目录浏览时频繁的页面闪烁影响用户体验。
- **选择的方案与 Trade-offs**：引入 quiet navigation，通过 one-frame landings 和 slow-scan loading pill 优化体验。增加了实现复杂度，但提升了用户体验。

**ADR-016: Collapsed ToolRow for Web Cards**
- **背景与痛点**：多种 card 的工具行导致 card 交互复杂。
- **选择的方案与 Trade-offs**：将多种 card 的工具行统一为折叠的 ToolRow，简化交互模式。牺牲了部分 card 的独立性，换取了交互一致性。

**ADR-017: Session Archive as Registry**
- **背景与痛点**：session 删除后无法恢复。
- **选择的方案与 Trade-offs**：引入 session 归档机制，通过 `archivedSessionIds` 集合管理归档 session。增加了存储开销，但获得了 session 恢复能力。

**ADR-018: Locale Seat in Slot Framework**
- **背景与痛点**：locale 管理分散在多个组件中，难以统一。
- **选择的方案与 Trade-offs**：引入 locale seat，通过 slot 框架管理 locale 状态。增加了 slot 框架的复杂度，但获得了 locale 的统一管理。

### 产品 Roadmap 支撑

- **Workspace Directory Browser** 支持了 workspace 管理的 GUI 化，降低了用户配置 workspace 的门槛。
- **LLM Onboarding Config** 支持了 LLM provider 的配置和 onboarding，降低了用户配置 provider 的门槛。
- **Web Cards Presenter** 支持了工具输出的多样化渲染，提升了用户体验。
- **Session Archive** 支持了 session 的归档和恢复，增强了 session 的可靠性。
- **Locale System** 支持了多语言和本地化，增强了产品的国际化能力。
- **TUI Welcome** 支持了 TUI 首次运行引导，降低了新用户的上手门槛。

## 5. 开发者/架构师决策推断

### 开发者意图重建

- **思维模型**：开发者将 workspace directory browser 视为一个 "安静的浏览体验"——通过 one-frame landings 和 loading pill 避免频繁的页面闪烁，提供流畅的浏览体验。
- **优先级选择**：先建立 quiet navigation（核心体验），再建立 adaptive default（智能选择），最后建立 show-hidden toggle（高级功能）。这是 "用户体验先行" 的策略。
- **有意取舍**：选择了 quiet navigation 而非 instant navigation，因为 instant navigation 的实现复杂度更高，且可能导致数据加载不一致。

### 架构师决策推断

- **模块拆分粒度**：workspace directory browser 被拆分为 quiet navigation、adaptive default、show-hidden toggle，每个职责独立。这个粒度确保了每个功能可以独立测试和演进。
- **时机判断**：在 LLM onboarding config 建立后才引入 workspace directory browser，因为 directory browser 需要与 workspace 集成。
- **后续影响**：workspace directory browser 的引入使得 workspace 管理的 GUI 化成为可能，但也增加了 native 和 web 的行为差异。

### Code Review 视角

- **首先关注**：`feat(directory-picker-browse): quiet navigation — one-frame landings and a slow-scan loading pill` 和 `feat(client): typed locale standard seat in the slot framework`。这两个是核心架构变更。
- **会提出的问题**：quiet navigation 在慢网络下的行为是什么？locale seat 在多语言切换时的行为是什么？session archive 的磁盘清理策略是什么？
- **做得好的**：quiet navigation 的 one-frame landings 设计考虑了用户体验，locale seat 的 slot 框架设计考虑了扩展性。
- **可以改进的**：quiet navigation 在慢网络下的行为需要更完善的错误处理，locale seat 的多语言切换需要更完善的测试覆盖。

## 6. 技术债务与风险评估

### 已知风险 / 变通方案

- **Quiet Navigation 的慢网络行为**：在慢网络下，loading pill 可能长时间显示，影响用户体验。
- **Locale Seat 的多语言切换**：多语言切换时，所有 locale-dependent 组件需要重新渲染，可能导致性能问题。
- **Session Archive 的磁盘清理**：归档的 session 会占用磁盘空间，需要明确的清理策略。
- **Web Cards Presenter 的性能**：presenter card 的渲染逻辑可能影响 card 的加载速度。

### 建议的下一步

1. **Quiet Navigation 慢网络测试**：添加慢网络下的集成测试，确保 loading pill 的行为正确。
2. **Locale Seat 多语言切换性能**：优化 locale 切换时的组件重渲染，避免性能问题。
3. **Session Archive 清理策略**：实现 session archive 的清理策略，避免磁盘空间无限增长。
4. **Web Cards Presenter 性能基准**：建立 presenter card 的性能基准，确保不会显著影响 card 的加载速度。
